# Brand files

- `twisted-takes-logo-original.png`: the team's master logo (4000×4000, stacked mark above the
  "Twistedtakes" wordmark, white background). Keep this as the source; it is not published.

Web versions in `assets/images/` were cut from it (transparent background):

| File | Use |
| --- | --- |
| `logo-horizontal.png` (468×112, shown at 234×56) | Site header: mark beside the wordmark |
| `logo-stacked.png` | Footer |
| `favicon.png` (64×64) | Browser tab icon |
| `apple-touch-icon.png` (180×180) | Phone home-screen icon |
| `logo-mark-512.png` | Square mark for social profiles or default link previews |

To replace the logo, export new files at the same sizes and names, or change the paths in
`_includes/header.html`, `_includes/footer.html` and `_includes/head.html`.
